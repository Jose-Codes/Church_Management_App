# Church_Management_App

## Prerequisites
Install Node.js (LTS) if you don’t have it: https://nodejs.org

### Check in Terminal:

```
node -v
npm -v
```

### Run locally
Open Terminal and go to the project folder (the path has spaces, so use quotes):
```cd "/Church_Management_App/Parish Attendance Management System"```

### Install dependencies (first time only):
```npm install```

### Start the dev server:
```npm run dev```

Open the URL Vite prints, usually:
http://localhost:5173/

Leave that terminal window open while you use the app. Stop the server with Ctrl+C.

### Optional commands
Command	Purpose
```npm run build```
Production build into dist/
```npm run dev -- --host```
Reachable from other devices on your network
